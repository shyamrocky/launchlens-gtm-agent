## Reproduce from the repository root

Prerequisites: uv and an available Python 3.12 interpreter. No .env or workspace
file is needed. Install only the locked pypdf dependency in the project environment:

```sh
uv sync --locked --no-python-downloads
uv run --locked python tools/prepare_documents.py
uv run --locked python -m unittest discover -s tests -v
uv lock --check --offline --no-python-downloads
```

The tool's paths are resolved relative to its repository location, not shell cwd.
There are no arbitrary input paths or parser plugins. Input hashes and document
definitions are explicit in tools/prepare_documents.py. A changed approved source
requires a separately reviewed definition/reference update, not a bypass flag.
Missing/changed inputs, unreadable/encrypted/empty-page PDFs, parser diagnostics,
altered claims/references or unexplained text fail preparation before existing
output files are changed. Validated files replace their predecessors individually;
an interrupted two-file replacement is not a transactional release. Consumers must
check pages.jsonl against the manifest digest before using it. No consumer exists
yet. Malformed/truncated output is not an accepted preparation.

## Content and normalization contract

Each JSONL record retains raw_text, normalized_text, page number, stable record ID,
document ID/version, authority, repository-relative source path, approved Drive
URL, PDF hash, parser version, observed IDs, links and per-rule change counts.
URI annotations retain their PDF rectangles; visible labels remain in page text.
Their placement was visually checked in these two PDFs, not inferred by a generic
label-to-rectangle algorithm.

Evidence spans locate the complete 15 PROD register statements and seven REQ
requirements, including their inline qualifications and references, in normalized
text. Offsets are zero-based Unicode character indexes; end is exclusive.
validated_block_spans additionally locate all 96 authored blocks, including shared
qualifications, document authority, unknowns, citation titles and dates. They are
validation locators, not retrieval chunks or reconstructed semantic paragraphs.

Normalization converts CRLF/CR to LF and NBSP to space, removes line-end spaces/tabs
and collapses runs of more than two newlines to two. It does not join lines,
dehyphenate, lowercase, Unicode-fold, alter punctuation, rewrite content or remove
headers/footers. **Actual changes across these five pages: zero**; raw and normalized
text are identical. Source headers/footers and historical draft labels remain as
extracted. Owner acceptance remains governed by canonical milestone records, not
those preserved labels.

Markdown is a validation reference only. Comparison permits whitespace differences,
renders Markdown headings as their visible text, preserves PRD bullet markers and
compares Product Brief bullets by their rendered text (the PDF omits the marker).
Markdown links are compared using their visible labels plus separately verified
annotation destinations. None of these comparison transformations rewrites the
stored PDF extraction. Every authored block must match completely and in order;
unexplained body text is rejected. Runtime uses explicit fixed-document checks,
not a general-purpose JSON Schema interpreter. The published schema documents the
format for future consumers; no schema-validation framework was installed.

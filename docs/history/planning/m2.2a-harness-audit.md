A premature finish must not declare completion. Prefer returning explicit unmet
requirements for bounded further research; retain the existing execution budget.
No general topic classifier, additional agent or new framework is necessary.

adapter references/history nevertheless survive reset and must be cleared/discarded.

## The context fix in plain English

Continue retrieving relevant passages using the existing Pinecone tool. Keep each
complete evidence_payload unchanged in run state. Build a separate model-facing
view from the existing structured fields; embedding_text remains vector-search
input, not a substitute for qualifications in the LLM context.

1. Each returned passage keeps chunk/unit ID, primary_text, authority, scoped
   claim/source mappings, direct citations, provenance and applicable limitations.
2. Preserve required context and source-reference roles. Deduplicate identical
   shared material once, retaining explicit links back to every passage it qualifies.
   Keep missing-reference/partial-evidence flags and warnings visible.
3. Normalize Notion PMM blocks into readable ordered text, headings and table cells,
   retaining relevant URLs and synthetic labels. Start with loss-preserving content
   normalization rather than speculative semantic selection of PMM sections.
4. Include a compact, harness-authored launch decision with scope/date, permissions,
   unresolved conditions and source-record references, once per model request.
5. Keep native action/result history concise; refer to the current deduplicated
   context view instead of embedding whole source packets in every historical result.
   Derive context from current authoritative run state so Reset/new-run cannot leave
   an independent old evidence history available to a later run.
6. Enforce an explicit context bound and fail visibly when required material cannot
   fit. Do not silently cut qualifiers, sources or warnings. Source IDs, hashes and
   truncation-free handling are not proof of semantic correctness.

A stateless API still needs necessary current context on each request. The target
is removing redundant representations and irrelevant API wrappers, not promising
that evidence can be sent only once across the entire provider conversation.
No freeform LLM summarization, corpus rebuild, chunk regeneration, Pinecone change,
retrieval retuning, separate evidence database, new dependency or infrastructure.
